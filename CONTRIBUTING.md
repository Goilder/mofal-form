# Contributing

Thanks for helping improve Mofal Form.

1. Use a Node.js version supported by Angular 21.
2. Run `npm ci`, then `npm run build`.
3. Keep public exports in `projects/mofal-form/src/public-api.ts`.
4. Include a clear description and build result in pull requests.

The demo is in `projects/demo`. It should stay usable with keyboard navigation and narrow screens.
