# Mofal Form

Небольшая библиотека компонентов форм для Angular 21: карточка формы, поле ввода или textarea и кнопка. Поля поддерживают Angular Reactive Forms через `ControlValueAccessor`. В репозитории есть демонстрационное приложение.

**Состояние:** стартовая версия 0.1.0. Библиотека и демо собираются; отправка формы в демо работает только локально, без сервера. Пакет пока не опубликован в npm.

## Быстрый запуск

~~~bash
npm install
npm run build:lib
npm start
~~~

Откройте `http://localhost:4200`. Чтобы получить установочный архив npm, выполните `npm pack` в папке `dist/mofal-form` после сборки.

Подробное описание компонентов и примеры использования находятся в [основном README](README.md) и [документации](docs/components.md).
