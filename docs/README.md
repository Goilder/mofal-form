# Documentation

Mofal Form is a small Angular 21 library for composed forms. Start with the [component reference](components.md), then use the guides below for implementation details.

| Guide | Focus |
| --- | --- |
| [Reactive form validation](guides/reactive-forms.md) | Connect `mf-field` to Angular Forms and show errors |
| [Theming](guides/theming.md) | Customize colors, typography, and surfaces |
| [Accessibility](guides/accessibility.md) | Labels, feedback, focus, and keyboard use |
| [Offline study form reference](examples/README.md) | A standalone example of a longer form interaction |

The [offline study example](examples/security-study.html) is a self-contained HTML reference for interaction design. It does not import the Angular package or extend its public API. Its companion notes explain which patterns map to Mofal Form components.
